# Block Blast

Статическая браузерная головоломка на HTML, CSS и JavaScript. Для запуска не нужны сервер, сборщик или зависимости: открой `index.html` в браузере.

## Игра

- Выбери одну из трёх фигур и поставь её на свободные клетки поля 8×8.
- Полная строка или колонка очищается. За размещённые блоки и очищенные линии начисляются очки.
- После каждого хода с очисткой линии палитра переключается внутри выбранного режима. В светлом и тёмном режиме по шесть монохромных тем; неоновая тема светится яркими оттенками.
- Режим оформления, язык интерфейса и рекорд сохраняются в браузере на этом устройстве.

## Публикация через GitHub Pages

Создай пустой репозиторий на GitHub, затем привяжи его и отправь существующие коммиты:

```sh
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

В настройках репозитория открой **Settings → Pages** и выбери публикацию из ветки `main`, папка `/ (root)`. Сборка не нужна.

Игровые файлы разделены по назначению: `index.html` задаёт структуру страницы, `styles.css` отвечает за оформление, `game.js` содержит логику игры.
